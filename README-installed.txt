AdminConsole 0.1.17 — Русский / English

РУССКИЙ

Запустите Admin Console через рабочий стол, меню «Пуск» или
Start Admin Console.exe в папке установки.
Выберите CMD или Windows PowerShell и обычный либо административный запуск.
Для административного режима Windows покажет запрос UAC.

Язык: выберите Русский / English в правом верхнем углу.
Запуск по умолчанию: выберите режим и нажмите «Сохранить».
Для возврата к настройкам удерживайте Shift при запуске либо выберите
«Настройки» в меню значка на панели задач.

Панель задач: откройте настройки, нажмите правой кнопкой по значку
приложения и выберите «Закрепить на панели задач».

Удаление: закройте приложение, открепите значок от панели задач и избранного
«Пуска», затем удалите AdminConsole через список установленных приложений
в настройках Windows. Также можно запустить unins000.exe в папке установки.
Деинсталлятор удаляет установленные файлы, созданные им ярлыки и настройки.
Посторонние файлы в папке установки остаются на месте.
Чтобы обновить или изменить папку установки, используйте установщик;
не переносите установленную папку вручную.

ENGLISH

Launch Admin Console from the desktop, Start menu, or Start Admin Console.exe
in the installation folder. Choose CMD or Windows PowerShell, normally or
as administrator. Administrator mode requires Windows UAC approval.

Language: choose Русский / English in the upper-right corner.
Default launch: select a mode and click Save.
To reopen settings, hold Shift while launching or choose Settings from the
taskbar icon's context menu.

Taskbar: open settings, right-click the application's taskbar icon and choose
Pin to taskbar.

Remove: close the app, unpin its taskbar and Start pins, then uninstall
AdminConsole from Windows Settings / installed apps. You can also run
unins000.exe in the installation folder. Uninstall removes installed files,
shortcuts created by Setup, and preferences. Unrelated files are preserved.
Use Setup to update or change the installation folder; do not move an installed
folder manually.
